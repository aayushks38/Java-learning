# Compound Interest Calculator (Java)

A console-based Java program to calculate compound interest
based on principal, rate, time, and compounding frequency.

## Formula Used
A = P (1 + r / n)^(n × t)

## Concepts Used
- Scanner
- Math.pow()
- User input
- Formatted output

## How to Run
javac CompoundInterestCalculator.java

java CompoundInterestCalculator
