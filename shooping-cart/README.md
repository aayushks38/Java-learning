# Shopping Cart (Java)

A console-based shopping cart application written in Java.
It supports Buy 1 Get 1 Free and percentage discount offers.

## Features
- Buy 1 Get 1 Free logic
- 10% discount for bulk purchase
- Simple bill calculation

## Concepts Used
- Scanner
- If-Else
- Arithmetic operations

## How to Run
javac ShoppingCart.java


java ShoppingCart
